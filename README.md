# ⚔️ Blade of the Night

**Blade of the Night** is a moonlit, pixel-art demon-hunting adventure game built using HTML, CSS, and JavaScript.

Explore mysterious locations, fight dangerous demons, defeat powerful bosses, upgrade your sword and abilities, and save the land from the Demon King.

## 🎮 Game Overview

- **Game Name:** Blade of the Night
- **Genre:** 2D Action / Adventure / Platformer
- **Graphics:** Pixel Art
- **Technology:** HTML5, CSS3, JavaScript
- **Rendering:** HTML5 Canvas
- **Platform:** Web Browser
- **Installation:** Not required

## ✨ Features

- 🌙 Beautiful moonlit pixel-art environments.
- ⚔️ Sword combat and demon battles.
- 👹 Multiple enemies and powerful boss fights.
- 🏃 Player movement, jumping, and dashing.
- ❤️ Health and damage system.
- 🪙 Coin collection and reward system.
- 🛒 Boss reward shop with character upgrades.
- 🤝 Two sword-wielding companions who assist in battles.
- 🔵 Checkpoint system.
- 🌌 Four unique game environments.
- 🔄 Restart functionality.
- 🏆 Final victory against the Demon King.

## 🗺️ Game Stages

The adventure contains four different stages:

| Stage | Location | Boss |
|---|---|---|
| 1 | Forest Path | Hand Demon |
| 2 | Mountain Village | Spider Demon |
| 3 | Snowy Temple | Blood Moon Demon |
| 4 | Blood Moon Castle | Final Demon King |

Each stage has its own atmosphere, enemies, and boss encounter.

## 🎮 Controls

| Key | Action |
|---|---|
| ← | Move Left |
| → | Move Right |
| ↑ | Jump |
| Space | Jump |
| E | Sword Slash |
| Z | Dash |
| Enter | Restart after winning or losing |

## 🛒 Upgrade System

Defeating a boss rewards the player with **50 coins**.

Each upgrade costs 50 coins.

| Upgrade | Benefit |
|---|---|
| ❤️ Health Upgrade | +10 Maximum HP |
| ⚔️ Damage Upgrade | +2 Sword Damage |
| 👟 Speed Upgrade | Increases Movement Speed |

Choose upgrades strategically to make later boss battles easier.

## 🚀 How to Play

1. Download or clone this repository.
2. Locate the `index.html` file.
3. Open `index.html` in a modern web browser.
4. Start playing!

No installation, server, or internet connection is required.

## 🛠️ Technologies Used

- **HTML5:** Game structure and interface.
- **CSS3:** Styling, layout, and responsive design.
- **JavaScript:** Game mechanics, player movement, enemy AI, combat, and progression.
- **HTML5 Canvas:** Pixel-art graphics and game rendering.

## 🎯 Objective

Your mission is to travel through all four locations, defeat demons and powerful bosses, collect coins, upgrade your abilities, and defeat the Final Demon King.

**Defeat the darkness. Protect the land. Bring back the dawn!**
